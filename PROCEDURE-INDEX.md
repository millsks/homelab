as a stub because [`docs/OWNERSHIP.md`](docs/OWNERSHIP.md) already points at it, and a dangling
reference in the ownership table is worse than an empty file with a stated owner.

Story 1.2 defines the Index's structure and the dual-form contract it enforces: a Procedure is a
Runbook **and** its Automation, cross-referenced by name, with its owning layer recorded. An entry
missing either half is reported as an incomplete Procedure. Do not add entries here before 1.2
establishes what an entry is — entries written against a guessed format are the first thing 1.2
would have to undo.
